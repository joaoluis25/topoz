# Projetos enviados — integração gradual e licenciamento

Os projetos foram inspecionados em seu **formato ZIP** e avaliados como referências, não copiados para a aplicação pública. O front-end TOPOZ é HTML/CSS/JavaScript estático com Supabase; a compatibilidade direta desses repositórios não foi assumida.

| Projeto | Licença identificada no ZIP | Tratamento nesta entrega |
|---|---|---|
| `anki-main` | AGPL-3.0-or-later (com componentes BSD) | Inspiração conceitual para revisão; **não copiar código** para produto fechado sem análise das obrigações da AGPL. |
| `learnharness-main` | AGPL-3.0 | Não incorporado diretamente; integrar conceitos apenas após auditoria técnica e jurídica. |
| `academic-research-skills-3.24.3` | CC BY-NC 4.0 | **Restrição comercial**; evitar reaproveitamento de conteúdo protegido na versão monetizada. |
| `OpenMAIC-main` | MIT no projeto principal; subcomponentes com licenças diferentes | Referência para Estúdio, avaliação e apresentações; portabilidade e dependências ainda não validadas. |
| `openwhispr-main` | MIT no projeto principal; dependências diversas | Referência para arquitetura de transcrição; não integra diretamente ao site sem backend STT, custos e privacidade. |
| `wisemapping-open-source-develop` | WiseMapping Public License 1.0 (WPL) | Exige análise de atribuição/condições; não copiar motor ou interface nesta beta. |

**Decisão:** reutilizar princípios e projetar implementações próprias, seguras e adequadas ao Supabase. Essa etapa não declara integração plena desses projetos nem compatibilidade de licença concluída.
